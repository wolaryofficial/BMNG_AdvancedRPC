<h1 data-importer="text" align="center">AdvancedRPC for BeamNG.drive</h1>

###

<p data-importer="text" align="center">This mod is designed to extend the functionality of Discord Rich Presence in BeamNG.drive. It provides players with advanced customization options, allowing them to configure and personalize the information displayed in their Discord activity status.</p>

###

<p data-importer="text" align="center">The mod has its own dedicated page on the official BeamNG.drive repository.<br><br>This mod is open-source, and its source code is publicly available to everyone. You are free to modify, improve, or expand it — including adding features and functionality that the original author may not have thought of :)</p>

###

<p data-importer="text" align="center">If you want to use the mod with your own Discord Application ID, you will need the bridge application, which can be downloaded from the [Releases page](https://github.com/wolaryofficial/BMNG_AdvancedRPC/releases) .<br>The bridge is not included in the official BeamNG.drive repository version, as distributing it there may violate repository rules.<br><br>Simply download and run the bridge application, then configure the required settings directly in-game.</p>
